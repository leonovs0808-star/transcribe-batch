# Инструкция для ИИ-агента: установить transcribe-batch

Ты помогаешь пользователю поставить **transcribe-batch** — навык, который расшифровывает
аудио/видео в текст и размечает разговоры по спикерам. Работает и с файлами на
компьютере, и со ссылками (YouTube, ВК Видео, Рутуб, Кинескоп, Дзен, Vimeo,
Яндекс.Диск, Google Drive, прямая ссылка на файл). Пользователь, скорее всего, не
программист — веди его пошагово, без жаргона, объясняй что и куда нажать/вставить.

Движок по умолчанию — **Deepgram**: он работает из любой страны, включая Россию, и один
умеет различать голоса. Ключ нужен ровно один, его и получаем на шаге 3. Groq — опция
для тех, кто за пределами России и хочет бесплатно; предлагай его только если
пользователь сам об этом заговорил.

Инструкция одна на все системы и на всех агентов. **Ничего не спрашивай про операционную
систему и про то, кто ты — определи сам** по шагу 0, и дальше выдавай пользователю только
те команды, которые подходят именно его случаю. Не показывай ему варианты для чужих систем.

## Железное правило: настройки компьютера пользователя ты не трогаешь

НИКОГДА не проси пользователя менять настройки его VPN, прокси, Clash, файрвола или
системной сети — не переключать «Правила/Глобальный», не менять порты, не отключать
защиту. Это его рабочая инфраструктура, через неё у него может идти что-то ещё, и
ломать её ради одной расшифровки нельзя.

Это относится и к расшифровке: движок по умолчанию (Deepgram) работает напрямую
отовсюду, поэтому повода трогать сеть пользователя нет в принципе. Если пользователь
сам выбрал Groq и получил `HTTP 403` — это значит только одно: Groq не обслуживает его
страну. Правильное решение — вернуться на Deepgram, а не чинить его VPN.

## Шаг 0. Определись сам (не спрашивая пользователя)

**Какая система.** Если у тебя есть доступ к терминалу — просто выполни:

```bash
python3 -c "import platform; print(platform.system())"
```

`Darwin` = macOS, `Linux` = Linux, `Windows` = Windows. Если команда не нашлась — почти
наверняка Windows, там интерпретатор называется `python`, проверь `python --version`.
Если доступа к терминалу нет — спроси у пользователя одним коротким вопросом
(«у тебя Mac или Windows?»), не устраивая опрос.

Дальше по всей инструкции:
- macOS / Linux — команда `python3`, терминал bash/zsh
- Windows — команда `python`, терминал PowerShell

**Кто ты.** От этого зависит только одно — куда класть папку навыка:

| Ты | Папка навыков |
|----|---------------|
| Claude Code | `~/.claude/skills/transcribe-batch` |
| Codex | `~/.codex/skills/transcribe-batch` |
| Другой агент со своей папкой навыков | его папка навыков |
| Обычный чат в браузере (ChatGPT/Claude без доступа к терминалу) | любая обычная папка, например `~/transcribe-batch` — навыка не будет, останется скрипт, который запускают командой |

На Windows `~` в PowerShell не всегда раскрывается — пиши `$env:USERPROFILE\.claude\skills\transcribe-batch`.

Если ты в браузере без доступа к компьютеру пользователя — диктуй команды по одной, жди,
что он скопирует их в свой терминал и пришлёт вывод обратно. Ни ChatGPT, ни Claude в
браузере не видят файлы на его компьютере и ничего там сами не откроют.

**Как объяснить пользователю, что такое терминал:**
macOS — приложение «Терминал» (Cmd+Space → «Терминал»).
Windows — «PowerShell» (Пуск → набрать «PowerShell»).

## Шаг 1. Проверь зависимости

macOS / Linux:
```bash
python3 --version
ffmpeg -version
git --version
```

Windows (PowerShell):
```powershell
python --version
ffmpeg -version
git --version
```

Нужен Python **3.8 или новее**.

Один pip-пакет ставится по желанию — **yt-dlp**, он нужен только для ссылок на YouTube
и другие видеохостинги. Спроси пользователя, будет ли он давать такие ссылки. Будет —
поставь сразу, это одна команда (на Windows `python` вместо `python3`):

```bash
python3 -m pip install -U yt-dlp
```

Для файлов, папок, Яндекс.Диска, Google Drive и прямых ссылок он не нужен — без него
всё это работает.

- **Python отсутствует** — https://www.python.org/downloads/ (macOS/Windows) или
  `sudo apt install python3` (Linux). На Windows при установке обязательно отметить
  галочку «Add python.exe to PATH», иначе команда не найдётся. Если `python` открывает
  Microsoft Store вместо версии — это стандартная заглушка Windows, помогает та же
  переустановка с галочкой.
- **ffmpeg отсутствует**:
  - macOS: `brew install ffmpeg` (нет Homebrew — сначала `/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"`)
  - Linux: `sudo apt install ffmpeg`
  - Windows: `winget install Gyan.FFmpeg` (или `choco install ffmpeg`, или вручную
    с https://www.gyan.dev/ffmpeg/builds/ — сборка essentials, распаковать, папку `bin`
    добавить в PATH). После установки терминал надо открыть заново.
- **git отсутствует** — macOS: `xcode-select --install`; Windows: https://git-scm.com/download/win

Не продолжай, пока версия Python и ffmpeg не печатаются без ошибок.

обязательно выполни ту же команду создания `.env`. Без неё следующий шаг сломается.

## Шаг 3. Получи ключ Deepgram

1. Открой https://console.deepgram.com в браузере.
2. **Sign Up** → регистрация по почте (можно через Google или GitHub).
   **Карту не спрашивают.** На счёт сразу кладут $200, они не сгорают — это примерно
   700 часов расшифровки. Скажи об этом пользователю, его обычно волнует именно это.
3. В консоли слева выбери **API Keys** → **Create a New API Key** → любое название →
   права **Member** или **Owner** → создать.
4. Скопируй ключ — показывается один раз, потом его не восстановить; если потеряется,
   просто создай новый тем же способом.

**Что дальше с этим ключом.** Он должен попасть в файл `.env` в папке проекта (тот же,
что создался на шаге 2). Это ЕДИНСТВЕННОЕ место, куда он нужен.

**Основной способ — одной командой** (надёжнее ручного редактирования: `.env` — файл с
точкой в начале имени, в Finder/Проводнике он скрыт и двойным кликом его не найти).
Попроси пользователя прислать ключ, подставь его вместо `ВСТАВЬ_КЛЮЧ_СЮДА` и выполни
команду из папки проекта (на Windows — `python` вместо `python3`):

```bash
python3 -c "
import re
p = '.env'
key = 'ВСТАВЬ_КЛЮЧ_СЮДА'
s = open(p, encoding='utf-8').read()
s = re.sub(r'DEEPGRAM_API_KEY=.*', f'DEEPGRAM_API_KEY={key}', s)
open(p, 'w', encoding='utf-8').write(s)
print('OK, ключ записан в .env')
"
```

Напечаталось `OK, ключ записан в .env` — всё готово.

**Запасной способ — вручную**, если пользователь не хочет больше трогать терминал.
Предупреди, что `.env` скрытый, и объясни как его показать:
- macOS Finder: в папке проекта нажать **Cmd+Shift+.** (точка).
- Windows Проводник: вкладка **Вид** → включить **Скрытые элементы**.

Открыть `.env` в TextEdit/Блокноте, заменить плейсхолдер на реальный ключ:
```
DEEPGRAM_API_KEY=реальный_ключ_пользователя
```
и сохранить **как обычный текст**, не меняя имя файла (TextEdit и Блокнот любят
дописать `.txt` — проследи, чтобы файл остался именно `.env`).

## Шаг 3-бис. Только если пользователь за пределами России и хочет бесплатно

Groq даёт распознавание бесплатно, но не обслуживает Россию (там `HTTP 403`) и не умеет
различать голоса. Сам это не предлагай — только если пользователь спросил про бесплатный
вариант и живёт там, где Groq работает.

1. https://console.groq.com → **Sign In** → **API Keys** → **Create API Key**.
2. Вписать в тот же `.env` строкой `GROQ_API_KEY=gsk_...` — тем же способом, что выше.
3. Запускать с флагом:
   ```bash
   python3 transcribe.py "/путь" --groq
   ```

Если оба ключа лежат в `.env`, а Groq ответит 403, скрипт сам вернётся на Deepgram и
напишет об этом строкой в выводе.

## Шаг 4. Проверь установку одной командой

```bash
python3 transcribe.py --check
```

Она сама печатает ОС, версию Python, найден ли ffmpeg и ffprobe, задан ли ключ, есть ли
прокси. Не иди дальше, пока в конце не появится «Готово к работе». Чего не хватает —
подсказка по установке идёт в том же выводе.

## Шаг 5. Тестовый прогон

Попроси пользователя назвать один короткий файл (лучше до 5 минут). Запусти:

```bash
python3 transcribe.py "/путь/к/тестовому/файлу"
```

Файла под рукой нет — проверь на ссылке, это работает так же:

```bash
python3 transcribe.py "https://youtu.be/<короткое видео>"
```

Рядом с файлом должен появиться `<имя>.md` с текстом. Покажи содержимое пользователю,
спроси, устраивает ли качество.

## Шаг 6. Массовая расшифровка

Сначала план, без запуска:

```bash
python3 transcribe.py "/путь/к/папке" --plan
```

Покажи список, подтверди, что это нужные файлы. Затем настоящий запуск:

```bash
python3 transcribe.py "/путь/к/папке"
```

Для больших папок это может занять часы — предупреди.

- macOS / Linux, чтобы не держать окно: `nohup python3 transcribe.py "/путь" > /tmp/transcribe.log 2>&1 &`,
  дальше следить через `tail -20 /tmp/transcribe.log`.
- Windows: `nohup` нет — просто предупреди, чтобы не закрывал окно терминала до конца.

## Шаг 7. Скажи, как этим пользоваться дальше

Если навык лёг в папку навыков (Claude Code или Codex) — объясни главное: **больше команды
набирать не нужно**. В любом новом чате достаточно написать «расшифруй /путь/к/папке» —
агент сам найдёт навык и запустит скрипт.

Если это обычная папка (браузерный чат) — покажи одну команду запуска, которую он будет
копировать каждый раз.

## Расскажи про ссылки

Это вторая вещь, ради которой берут инструмент, — покажи её пользователю явно:

- Вместо пути можно дать **ссылку**, и скачивать себе ничего не надо:
  ```bash
  python3 transcribe.py "https://youtu.be/xxxxxxxx"
  python3 transcribe.py "https://disk.yandex.ru/d/xxxxxxxx"
  python3 transcribe.py "https://drive.google.com/file/d/xxxxxxxx/view"
  ```
- Понимает: YouTube, ВК Видео, Рутуб, Кинескоп, Дзен, Vimeo, Яндекс.Диск, Google Drive,
  прямая ссылка на файл.
- Скачанное скрипт убирает за собой сам — на диске остаётся только расшифровка.
- Расшифровка по ссылке ложится в текущую папку. Другое место — флаг `--out "/путь"`.
- Ссылка на **папку** Яндекс.Диска не сработает: нужна ссылка на конкретный файл. Хочет
  расшифровать целую папку с Диска — пусть скачает её себе и даст путь, так даже быстрее.

## Расскажи про разделение по спикерам

Это главное, ради чего берут Deepgram, — скажи об этом пользователю явно:

- Записи **длиннее 3 минут** размечаются сами: «Спикер 1: …», «Спикер 2: …». Созвон,
  интервью, планёрка — видно, кто что сказал.
- Короткие записи идут сплошным текстом: надиктованная мысль, метки в ней только мешают.
- Перебить решение можно флагами: `--speakers` (размечать всегда) и `--no-speakers`
  (не размечать никогда).
- Имён движок не знает, только «первый» и «второй» — кто есть кто, пользователь
  подставляет сам по смыслу реплик.

## Если что-то не работает

- **«ffmpeg не найден в PATH»** — ffmpeg не установлен или терминал не перезапущен после
  установки. Проверь `ffmpeg -version`.
- **«DEEPGRAM_API_KEY не найден»** — ключ не вписан в `.env`, или `.env` лежит не рядом с
  `transcribe.py`.
- **`HTTP 401`** — ключ неверный или скопирован с лишним пробелом. Создай новый.
- **`HTTP 403`** — это бывает только на `--groq`: Groq не обслуживает страну пользователя
  (так в РФ). Решение — убрать флаг `--groq` и работать на Deepgram. В настройки
  VPN/прокси/Clash пользователя не лезь: это его инфраструктура, и для расшифровки она
  не нужна.
- **Ссылка на YouTube не качается** — проверь, стоит ли yt-dlp (`python3 -m pip show yt-dlp`).
  Стоит, но видео не берётся — обнови: `python3 -m pip install -U yt-dlp`. YouTube
  периодически меняет защиту, свежая версия обычно уже умеет её обходить. Приватное
  видео требует cookies — файл `youtube_cookies.txt` рядом с `transcribe.py`.
- **Спикеры не разделились на явном диалоге** — проверь, что запись длиннее 3 минут или
  что стоит флаг `--speakers`. Если и так не делит — возможно, голоса записаны одним
  микрофоном и очень похожи; это предел движка, а не поломка.
- **Текст на английском вместо русского** — язык определяется автоматически; если
  стабильно путает, сообщи автору (см. README).
