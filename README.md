# transcribe-batch

Скармливаешь скрипту видео/аудио или целую папку — рядом с каждым файлом появляется
`.md` с текстовой расшифровкой. Разговоры размечаются по спикерам («Спикер 1 / Спикер 2»).

Работает **из России напрямую**, без VPN и прокси. Один репозиторий на всё:
**macOS, Linux и Windows**, **Claude Code и Codex**. Ставится в папку навыков твоего ИИ —
и дальше ты просто пишешь в чат «расшифруй вот эту папку», без команд.

## Установка как навык (тогда работает по фразе в чате)

Репозиторий одновременно и обычный скрипт, и готовый навык. Клонируй его в папку
навыков своего агента — он подхватит `SKILL.md` сам:

**Claude Code** (macOS / Linux):
```bash
git clone https://github.com/leonovs0808-star/transcribe-batch.git ~/.claude/skills/transcribe-batch
```

**Codex** (macOS / Linux):
```bash
git clone https://github.com/leonovs0808-star/transcribe-batch.git ~/.codex/skills/transcribe-batch
```

**Windows (PowerShell)** — то же самое, только путь пишется так:
```powershell
git clone https://github.com/leonovs0808-star/transcribe-batch.git $env:USERPROFILE\.claude\skills\transcribe-batch
# или для Codex:
git clone https://github.com/leonovs0808-star/transcribe-batch.git $env:USERPROFILE\.codex\skills\transcribe-batch
```

Дальше зайди в эту папку, создай `.env` и впиши ключ (см. «Ключ» ниже). После этого в
любом чате достаточно написать «расшифруй /путь/к/папке» — агент сам вызовет скрипт.

## Что делает

- Проходит по папке (рекурсивно) или берёт один указанный файл
- Понимает `.mp4 .mov .mkv .webm .avi .m4v .mp3 .m4a .aac .wav .ogg .opus`
- Кладёт результат в `<имя файла>.md` рядом с исходником
- Уже расшифрованные файлы пропускает — safe перезапускать на той же папке
- **Сам решает, размечать ли спикеров:** запись длиннее 3 минут считается разговором и
  размечается («Спикер 1: …»), короткая идёт сплошным текстом. Короткая запись почти
  всегда надиктованная мысль, метки в ней только мешают. Перебивается флагами
  `--speakers` / `--no-speakers`.

## Что нужно

- **Python 3.8+** — на Mac и Linux обычно уже стоит; на Windows — с
  https://www.python.org/downloads/ (при установке отметить галочку
  «Add python.exe to PATH»)
- **ffmpeg**:
  - macOS: `brew install ffmpeg`
  - Linux: `sudo apt install ffmpeg`
  - Windows: `winget install Gyan.FFmpeg` (или `choco install ffmpeg`, или вручную
    с https://www.gyan.dev/ffmpeg/builds/ — сборка essentials, папку `bin` добавить в PATH)
- **Бесплатный ключ Deepgram** — https://console.deepgram.com/

Никаких pip-пакетов ставить не надо: скрипт использует только стандартную библиотеку Python.

## Ключ

```bash
cp .env.example .env      # Windows PowerShell: copy .env.example .env
```

Открой `.env` и впиши свой ключ Deepgram вместо `твой_ключ_отсюда_console.deepgram.com`.

Ключ берётся на https://console.deepgram.com/ — регистрация по почте, **карту не
спрашивают**. На счёт сразу кладут $200, и они не сгорают. По текущей цене nova-3
($0,0043 за минуту) это примерно **700 часов** расшифровки — столько личных записей
обычно не набирается за годы.

## Проверка установки

```bash
python3 transcribe.py --check
```

Печатает ОС, версию Python, найден ли ffmpeg/ffprobe, задан ли ключ, есть ли прокси.
Чего не хватает — подсказка идёт в том же выводе.

## Запуск руками

На Windows везде пиши `python` вместо `python3`.

Один файл:
```bash
python3 transcribe.py "/путь/к/видео.mp4"
```

Вся папка (рекурсивно):
```bash
python3 transcribe.py "/путь/к/папке"
```

Только план, без запуска:
```bash
python3 transcribe.py "/путь/к/папке" --plan
```

Принудительно размечать спикеров (или наоборот, не размечать никогда):
```bash
python3 transcribe.py "/путь/к/папке" --speakers
python3 transcribe.py "/путь/к/папке" --no-speakers
```

## Какие модели распознавания используются

| Движок | Модель | Когда работает |
|--------|--------|----------------|
| Deepgram | `nova-3` | по умолчанию; **из России работает напрямую**, размечает спикеров |
| Groq | `whisper-large-v3` | флаг `--groq`; бесплатно, но **из России отдаёт HTTP 403** |

Обе прописаны в `transcribe.py` константами `GROQ_MODEL` и `DEEPGRAM_MODEL` в начале
файла — если захочешь поменять, менять надо только там, больше нигде они не зашиты.

Почему именно эти:

- **nova-3** — новее и точнее, чем `nova-2`, на живой русской речи: аккуратнее
  пунктуация, меньше выдуманных слов, чище разделение по спикерам. Проверено сравнением
  двух моделей на одной и той же записи разговора.
- **whisper-large-v3** — самая точная модель у Groq. У них есть ещё
  `whisper-large-v3-turbo`: быстрее и дешевле, но заметно слабее на русском.

### Если ты за пределами России — можно бесплатно на Groq

Там, где Groq обслуживает страну, он бесплатен и его лимита хватает на личное
использование. Возьми ключ на https://console.groq.com/keys, впиши в `.env` строкой
`GROQ_API_KEY=gsk_...` и запускай с флагом:

```bash
python3 transcribe.py "/путь/к/папке" --groq
```

Спикеров Whisper не различает — разметка по ролям работает только на Deepgram. Если
Groq ответит `HTTP 403` (страна не обслуживается), а ключ Deepgram в `.env` лежит,
скрипт сам перейдёт на Deepgram и напишет об этом в выводе.

## Частые вопросы

**Почему звук не сжимается перед отправкой?**
Потому что от сжатия ломается разделение по спикерам. Проверено на живой записи: та же
запись даёт двух спикеров в оригинале и одного после прогона через mp3 32 kbps —
кодек стирает тембровую разницу между голосами. Поэтому аудиофайлы уходят как есть, а
из видео звук вынимается в FLAC (без потерь). Для Groq звук всё-таки жмётся — у него
лимит 25 МБ на файл.

**Аудио уходит в облако — это безопасно?**
Deepgram (и Groq для `--groq`) — облачные сервисы, файл уходит на их серверы для
распознавания. Актуальную политику хранения данных смотри на их сайтах
(deepgram.com, console.groq.com) — для конфиденциальных материалов оценивай риски сам.

**Скрипт пишет, что ffmpeg не найден**
Проверь `ffmpeg -version` в терминале. Если только что установил — открой окно терминала
заново, PATH подхватывается при запуске.

**Долгий прогон на Windows**
`nohup` там нет — просто не закрывай окно, пока идёт расшифровка.

**Спикеры перепутались местами**
Движок не знает имён, только «кто-то первый» и «кто-то второй» — имена подставляй сам.
На быстрых перебиваниях граница между репликами может съехать на слово: это особенность
разделения одного смешанного канала, а не поломка.
