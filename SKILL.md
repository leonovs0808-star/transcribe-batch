# transcribe-batch — расшифровка аудио/видео

Работает одинаково в Claude Code и в Codex, на macOS, Linux и Windows.

## Модели

- Deepgram — `nova-3` (по умолчанию; работает из любой страны, включая РФ; размечает спикеров)
- Groq — `whisper-large-v3` (флаг `--groq`; бесплатно, но из России отдаёт 403 и не различает голоса)

Заданы константами `GROQ_MODEL` и `DEEPGRAM_MODEL` в начале `transcribe.py`.
Просят поменять модель — меняй там, в других местах они не зашиты.

## Где лежит скрипт

`transcribe.py` — рядом с этим файлом SKILL.md, в этой же папке.

## Что делает

- Ссылка: YouTube, ВК Видео, Рутуб, Кинескоп, Дзен, Vimeo, Яндекс.Диск, Google Drive,
  прямая ссылка на файл — качает сам, скачанное убирает за собой
- Один файл или папка (рекурсивно): `.mp4 .mov .mkv .webm .avi .m4v .mp3 .m4a .aac .wav .ogg .opus`
- Кладёт результат в `<имя файла>.md` рядом с исходником
- Уже расшифрованные файлы пропускает — safe перезапускать
- Разметку по спикерам включает сам: запись длиннее 3 минут размечается «Спикер 1/2»,
  короткая идёт сплошным текстом

## Шаг 0. Определи, чем запускать

Скрипту нужен Python 3.8+ и ffmpeg. Единственный pip-пакет — `yt-dlp`, и он нужен
только для ссылок на видеохостинги (см. «Шаг 2»); во всём остальном хватает
стандартной библиотеки.

- **macOS / Linux** — команда `python3`
- **Windows** — команда `python` (в PowerShell `python3` обычно открывает Microsoft Store)

Дальше в примерах написано `python3` — на Windows подставляй `python`.

## Шаг 1. Проверь установку одной командой

```
python3 "<путь_к_папке_скила>/transcribe.py" --check
```

Она печатает ОС, версию Python, найден ли ffmpeg/ffprobe, задан ли ключ, есть ли прокси.
Чего не хватает — подсказка по установке идёт в том же выводе. Не запускай расшифровку,
пока `--check` не скажет «Готово к работе».

Если нет ключа — попроси пользователя взять бесплатный на https://console.deepgram.com/
(карту не спрашивают, на счёт сразу кладут $200 — около 700 часов расшифровки), и впиши
командой:

```
python3 "<путь_к_папке_скила>/transcribe.py" --set-key deepgram КЛЮЧ
```

Без КЛЮЧА в конце команда спросит его вводом — тогда ключ не попадёт в переписку, это
предпочтительный вариант, если пользователь готов выполнить команду сам. Ключ в чате
не повторяй и в память не сохраняй.

## Шаг 2. Запуск

Один файл:

```
python3 "<путь_к_папке_скила>/transcribe.py" "/абсолютный/путь/к/файлу.mp4"
```

Вся папка:

```
python3 "<путь_к_папке_скила>/transcribe.py" "/абсолютный/путь/к/папке"
```

Ссылка (видео, Яндекс.Диск, Google Drive, прямой файл):

```
python3 "<путь_к_папке_скила>/transcribe.py" "https://youtu.be/xxxxxxxx"
```

Расшифровка по ссылке ложится в ТЕКУЩУЮ папку. Нужна другая — флаг `--out`:

```
python3 "<путь_к_папке_скила>/transcribe.py" "<ссылка>" --out "/путь/к/папке"
```

Для ссылок на видеохостинги нужен yt-dlp. Нет — скрипт скажет об этом и подскажет
команду установки (`python3 -m pip install -U yt-dlp`). Ставь без лишних вопросов,
если пользователь дал такую ссылку. Для Яндекс.Диска, Google Drive и прямых ссылок
yt-dlp не нужен.

Ссылка на ПАПКУ Яндекс.Диска не поддерживается — скрипт скажет об этом прямо.
Нужна целая папка с Диска — пусть пользователь скачает её себе, дальше обычный путь.

Только план (что будет обработано, без запуска):

```
python3 "<путь_к_папке_скила>/transcribe.py" "/путь" --plan
```

## Разделение по спикерам

Решение принимается по длительности: длиннее 3 минут — размечаем («Спикер 1: …»),
короче — сплошной текст. Флаги нужны, только если пользователь просит иначе:

```
python3 "<путь_к_папке_скила>/transcribe.py" "/путь" --speakers      # размечать всегда
python3 "<путь_к_папке_скила>/transcribe.py" "/путь" --no-speakers   # не размечать никогда
```

Имён движок не знает — только «Спикер 1» и «Спикер 2». Кто есть кто, определяй по смыслу
реплик и подставляй сам, если пользователь просит имена.

**Звук перед отправкой не пережимай своими руками** и не «оптимизируй» вызов ffmpeg в
скрипте: сжатие в mp3 стирает тембровую разницу между голосами, и разделение по спикерам
ломается. Скрипт специально шлёт аудиофайлы как есть, а из видео вынимает звук в FLAC.

## Если пользователь за пределами России и хочет бесплатно

```
python3 "<путь_к_папке_скила>/transcribe.py" "/путь" --groq
```

Нужен `GROQ_API_KEY` в `.env` (https://console.groq.com/keys). Спикеров Whisper не
различает. Сам этот флаг не предлагай — только по просьбе пользователя.

Если Groq отдал `HTTP 403` — страна не обслуживается. Скрипт сам вернётся на Deepgram,
когда ключ Deepgram есть в `.env`. **Настройки VPN, прокси, Clash и файрвола пользователя
не трогай** — ни сам, ни просьбой к нему. Это его рабочая инфраструктура, и для
расшифровки её менять не нужно.

## Прогресс для длинных прогонов

- macOS / Linux: `nohup ... > /tmp/transcribe.log 2>&1 &`, дальше `tail -f`.
- Windows: `nohup` нет. Либо просто не закрывать окно до конца прогона, либо
  `Start-Process` в отдельном окне. Предупреди пользователя, что окно должно жить.

## Отчёт

После запуска сообщи: сколько файлов найдено, какой движок, размечаются ли спикеры.
После завершения: сколько готово, пропущено, ошибок, куда легли `.md`.
